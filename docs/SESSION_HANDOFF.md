Олежка подтвердил первый реальный запуск: виртуальный фундамент работает.
Это первая завершённая контрольная точка проекта.

## Следующий инженерный шаг

Исправить корректное выключение из гостевой системы: команда `poweroff` в
минимальном BusyBox-окружении пока не дала ожидаемого результата. До этого
VirtualBox можно закрывать штатным действием «Выключить машину».

## Как продолжить на другом компьютере

```sh
git clone git@github.com:korshun199/KARLIN.git
cd KARLIN
code .
```

После открытия проекта в новом чате Codex достаточно сообщить:

```text
Продолжаем KARLIN. Прочитай AGENTS.md и docs/SESSION_HANDOFF.md.
```

История чата Codex между поверхностями может быть недоступна, поэтому этот
файл является переносимой инженерной памятью проекта.
