# Сохранность KARLIN

Компьютер — рабочее место, а не единственная копия проекта. Поломка,
падение, вода, кот, ваза и человек, который сел на ноутбук, не должны
уничтожить уже сохранённую работу.

## Что защищает GitHub

В GitHub сохраняются все отправленные коммиты:

- исходный код;
- документация;
- архитектурные решения;
- сценарии сборки;
- описание состояния проекта.

ISO, виртуальные диски, логи и кэш собираются заново и не являются резервной
копией исходников.

## Контрольная точка перед уходом

В корне проекта:

```sh
./tools/checkpoint.sh "Коротко описать, что сделано"
```

Команда проверяет Git, создаёт коммит и отправляет его в GitHub. Если в
проекте есть незакоммиченные изменения, это сознательная команда владельца,
а не фоновая телеметрия.

## Восстановление после потери компьютера

```sh
git clone git@github.com:korshun199/KARLIN.git
cd KARLIN
code .
```

После этого устанавливаются только инструменты новой машины: VS Code, Codex,
VirtualBox и зависимости сборки. Рабочие результаты восстанавливаются из
чертежей и исходников.

## Правило владельца

Перед переходом в другое место или завершением важной сессии должна быть
отправлена контрольная точка. Работа, которая существует только на диске
ноутбука, считается ещё не сохранённой.
