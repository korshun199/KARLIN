# Работа с KARLIN на разных компьютерах

## Модель

```text
дом ───────┐
работа ────┼── GitHub ── VPS
ноутбук ───┘
```

Каждая машина является заменяемой рабочей станцией. Ни одна из них не
содержит единственную «главную» копию проекта.

## Первый запуск на новом компьютере

```sh
git clone https://github.com/korshun199/KARLIN.git
cd KARLIN
code .
```

После клонирования на машине устанавливаются только её инструменты:
Linux, VS Code, Codex, VirtualBox или QEMU. Эти программы не смешиваются с
исходниками KARLIN.

## Переход между компьютерами

На старом компьютере:

```sh
git add .
git commit -m "Сохранить текущую работу"
git push
```

На новом компьютере:

```sh
./tools/sync.sh
```

Скрипт обновляет текущую ветку только при чистом рабочем каталоге. Он не
удаляет локальные файлы и не перезаписывает незакоммиченные изменения.

## VPS

VPS не является местом ручной разработки. Он получает код из GitHub и
проверяет воспроизводимость сборки, тесты и запуск виртуального стенда.
Позже это можно подключить как GitHub Actions или отдельный обработчик.

## Что синхронизируется

- исходный код;
- чертежи Blueprint;
- документация;
- сценарии сборки и проверки;
- архитектурные решения.

## Что не синхронизируется через Git

- секреты и токены;
- пароли и SSH-ключи;
- локальные настройки VS Code;
- ISO, диски и временные образы виртуальных машин;
- кэш и результаты сборки.
