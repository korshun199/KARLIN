# KARLIN

KARLIN — исследовательская система, которая превращает человеческую
потребность в маленький проверенный локальный инструмент.

## Границы проекта

- `foundation/` — Linux-фундамент и контракты, на которых работает KARLIN.
- `virtual/` — гостевая система и провайдеры виртуализации.
- `karlin/` — верхние слои системы, независимые от конкретного железа.
- `tools/` — общие технические инструменты разработки.
- `tests/` — проверки контрактов и поведения.
- `docs/` — философия, архитектура и решения.
- `build/` — временные результаты сборки; в Git не добавляется.

Первый пользовательский стенд VirtualBox находится в
`virtual/providers/virtualbox/`.

Запуск:

```sh
./virtual/providers/virtualbox/run.sh
```
