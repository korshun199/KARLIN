# Foundation

Фундамент KARLIN: Linux, ядро, драйверы, виртуальное или физическое железо
и адаптационный слой.

Эта часть отвечает только за предоставление проверенных возможностей верхним
слоям. Философия пользовательской системы сюда не переносится.

В будущем здесь появятся реализации и документация `KARLIN Socket` —
контракта между фундаментом и остальной системой.
