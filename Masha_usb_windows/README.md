# Маша — переносимое приложение для Windows

Проект оконного приложения с ИИ-агентом для работы с флешки на Windows 10/11.
Его основа — идеи и возможности нашей `AITunnel_USB_Console`. Приложение
должно запускаться на чистой Windows x64 с настроенным интернетом без установки
Python, .NET или дополнительных программ пользователем.

У `Masha.exe` собственные настройки и история; существующая консольная
версия остаётся самостоятельной программой. Оконная версия
подключается к AITunnel через API; история этого чата Codex автоматически в неё
не переносится.

**Состояние проекта:** рабочий функциональный прототип. Добавлены чат,
список моделей, баланс, журнал диалогов, вложения текста/изображений/PDF,
диктовка через распознавание и озвучка ответа. Поддержка зависит от модели;
реальные микрофон и динамики требуют проверки обычным запуском на рабочем столе.
Локальный инструмент PowerShell всегда доступен модели. Перед каждым запуском
программа показывает полную команду и ждёт отдельного подтверждения; без него
команда не выполняется. Команда работает с правами текущего пользователя Windows.

- [Архитектура приложения](ARCHITECTURE.md) — требования, устройство,
  совместимость с консолью, сборка и проверки.
- Каталог чат-моделей обновляется командой `python3 tools/update_chat_models.py`;
  приложение показывает пересечение каталога с моделями, доступными API-ключу.
- Цветовая схема хранится в `theme.json` рядом с `Masha.exe`; все поля, кнопки,
  подписи и модальные окна используют эту общую палитру. Если файл ошибочен,
  приложение выбирает встроенные контрастные значения. В единственной нижней
  строке слева расположены значки прикрепления и голосового ввода, в центре —
  системный статус и имена вложений с кнопкой `Очистить`, справа — выбор модели
  и крупная кнопка `ОТПРАВИТЬ`. Размер значков и ширина элементов справа задаются
  в `theme.json`.
  В шапке окна слева находится название `AI Model Masha 2026`, справа — подпись
  `Author: Sinelnikov Oleg 2026` и сразу за ней значок-шестерёнка для настроек.

Существующий консольный проект доступен в отдельной ветке репозитория
`codex/aitunnel-usb-console-standalone`; реальные ключи и диалоги в Git не
переносятся.

## Сборка приложения

Текущая разрабатываемая версия собирается командой `bash ./build-app.sh`, её
результат — `publish/app-win-x64/Masha.exe`. Последняя копия на тестовой флешке
находится в `D:\Masha_usb_windows\Masha.exe`. Ключ можно ввести в настройках:
без сохранения он действует до закрытия, а при выборе сохранения записывается
открытым текстом в `api_key.txt` рядом с EXE. Его нельзя помещать в Git.
Переносимые настройки и диалоги находятся в `config.json` и `sessions/` рядом
с EXE. Удаление ключа из файла выполняется вручную. Ввод — многострочный,
Ctrl+Enter отправляет сообщение. Поддерживаются UTF-8 текст до 1 МиБ,
изображения и PDF до 25 МиБ; приложение копирует вложения в `attachments/`,
отправляет провайдеру и сохраняет ссылки в журнале. Диктовка создаёт WAV в
`recordings/`; озвученный ответ сохраняется как MP3. Списки моделей распознавания
и озвучки загружаются из публичного каталога AITunnel, а допустимые голоса
подбираются для выбранной модели. Встроенный проигрыватель пока требует MP3.

`Masha.exe --self-test <пустая-папка>` проверяет историю, вложения, API-контракт,
вызов PowerShell и цикл инструмента с искусственным поставщиком; к API не обращается.
`Masha.exe --api-test <пустая-папка>` использует переменную `AITUNNEL_API_KEY`,
делает реальный платный запрос модели и сохраняет только результат проверки.
Приложение хранит собственные журналы в `sessions/`; прежние диалоги консольной
версии автоматически не импортируются. Одновременное использование её журналов
с консольной программой не проверено; каталоги у двух программ отдельные.

Первый демонстрационный прототип собирается отдельно:

На Linux нужен .NET SDK 10 и доступ к пакетам сборки. Пользователю на Windows
устанавливать SDK и среду .NET отдельно не нужно: сборка включает необходимые
компоненты. Запуск из каталога проекта:

```bash
bash ./build-prototype.sh
```

Скрипт ищет `dotnet` в PATH, затем в `/home/work/.masha-dotnet`; другой путь к
SDK можно задать переменной `DOTNET_BIN`. Результат —
`publish/prototype-win-x64/Masha.exe`. Это тестовая сборка под Windows x64;
совместимость с чистой Windows подтверждается отдельной проверкой на ней.

Для автоматической проверки окна на Windows можно запустить EXE с параметрами
`--smoke-test <пустая-папка>`. Программа нажмёт тестовую кнопку, сохранит в
указанную существующую папку `result.txt` и изображение `window.png` и закроется.
Существующие файлы с этими именами не перезаписываются. Этот режим не обращается
к AITunnel, ключу или истории диалогов.
