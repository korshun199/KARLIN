# Маша — переносимое приложение для Windows

Проект оконного приложения с ИИ-агентом для работы с флешки на Windows 10/11.
Его основа — идеи и возможности нашей `AITunnel_USB_Console`. Приложение
должно запускаться на чистой Windows x64 с настроенным интернетом без установки
Python, .NET или дополнительных программ пользователем.

Планируется отдельный запускаемый `Masha.exe`, переносимый каталог с настройками
и историей, а также сохранение существующей консольной версии. В окно добавим
выбор модели, прикрепление файлов и голосовой разговор. Программа
подключается к AITunnel через API; история этого чата Codex автоматически в неё
не переносится.

**Состояние проекта:** первое окно-прототип. Оно проверяет запуск интерфейса и
нажатие кнопки; подключения к ИИ, голоса, вложений и истории в нём пока нет.

- [Архитектура приложения](ARCHITECTURE.md) — требования, устройство,
  совместимость с консолью, сборка и проверки.

Существующий консольный проект доступен в отдельной ветке репозитория
`codex/aitunnel-usb-console-standalone`; реальные ключи и диалоги в Git не
переносятся.

## Сборка первого окна

На Linux нужен .NET SDK 10 и доступ к пакетам сборки. Пользователю на Windows
устанавливать SDK и среду .NET отдельно не нужно: сборка включает необходимые
компоненты. Запуск из каталога проекта:

```bash
bash ./build-prototype.sh
```

Скрипт ищет `dotnet` в PATH, затем в `/home/work/.masha-dotnet`; другой путь к
SDK можно задать переменной `DOTNET_BIN`. Результат —
`publish/prototype-win-x64/Masha.exe`. Это тестовая сборка под Windows x64;
совместимость с чистой Windows подтверждается отдельной проверкой на ней.

Для автоматической проверки окна на Windows можно запустить EXE с параметрами
`--smoke-test <пустая-папка>`. Программа нажмёт тестовую кнопку, сохранит в
указанную существующую папку `result.txt` и изображение `window.png` и закроется.
Существующие файлы с этими именами не перезаписываются. Этот режим не обращается
к AITunnel, ключу или истории диалогов.
