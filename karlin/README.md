# KARLIN upper layer

Здесь будут находиться компоненты, работающие поверх `KARLIN Socket`:

- оболочка взаимодействия с человеком;
- `Forge` — создание и проверка решений;
- `Blueprint` — описание потребности;
- `Leaf` — готовый локальный инструмент.

Этот каталог не должен зависеть от модели процессора, драйверов или
конкретного Linux-дистрибутива.
