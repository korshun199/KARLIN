# AITUNNEL

> Единый OpenAI-совместимый API к ведущим ИИ-моделям (GPT, Claude, Gemini, DeepSeek, Qwen, Kimi и другим) для пользователей из России. Один ключ, один формат запросов, оплата в рублях, VPN не требуется.

- Base URL: https://api.aitunnel.ru/v1
- Зеркало, если провайдер блокирует основной хост: https://ru-api.aitunnel.ru/v1
- Формат ключа: sk-aitunnel-…
- Формат запросов: OpenAI Chat Completions API

## Документация

- [Введение](https://aitunnel.ru/docs.md): base URL api.aitunnel.ru/v1, зеркало ru-api.aitunnel.ru/v1 при блокировке у провайдера (таймаут, Connection reset, Failed to fetch), авторизация, первый запрос, примеры на cURL/Python/JavaScript/Go/PHP, обзор возможностей и модель auto.
- [Баланс и оплата](https://aitunnel.ru/docs/payments.md): pay-as-you-go, способы оплаты, счёт для компаний от 5 000 ₽, УПД через ЭДО, акт сверки, криптовалюта через NOWPayments от 1 500 ₽ с бонусом +20%, авто-пополнение, проверка баланса, usage.cost и usage.cost_rub — одно число в рублях, тарифы, возврат, договор по запросу.
- [API-ключи](https://aitunnel.ru/docs/keys.md): создание ключа, лимит по балансу, бюджет, автосброс бюджета в 00:00 МСК (daily/weekly/monthly), срок, белый список моделей и IP, защита данных, сброс ключа — новый секрет, бюджет и настройки остаются; дублирование ключа — новый ключ с теми же настройками, без расходов.
