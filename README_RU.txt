AITUNNEL USB CONSOLE
====================

Переносимая консоль для Windows 10/11. Python и установка пакетов не нужны:
используется встроенный Windows PowerShell 5.1.

ПЕРВЫЙ ЗАПУСК
-------------
1. Скопируйте весь каталог AITunnel_USB_Console на флешку.
2. Откройте api_key.cmd в Блокноте.
3. Замените PASTE_YOUR_AITUNNEL_KEY_HERE на свой ключ AITunnel,
   сохранив строку в таком виде:
   set "AITUNNEL_API_KEY=sk-aitunnel-ВАШ_КЛЮЧ"
4. Дважды щёлкните START_AI_CONSOLE.cmd.

Ключ берётся из переменной окружения процесса и не показывается в консоли.
Но файл api_key.cmd содержит ключ открытым текстом: не теряйте флешку,
не отправляйте этот файл другим и отзовите ключ у провайдера при утечке.

НАСТРОЙКИ
---------
config.json задаёт адрес API, модель, максимальный размер ответа,
таймаут запроса и количество последних сообщений, сохраняемых в памяти.

Системные инструкции берутся из AGENTS.md рядом с программой. Если этого
файла нет, используется assistant_instructions.txt. Поэтому для другой
рабочей папки замените AGENTS.md рядом с программой на нужный файл правил.

По умолчанию выбрана модель gpt-6-luna и адрес https://api.aitunnel.ru/v1.
Если в предоставленной документации указан другой совместимый адрес,
поменяйте base_url в config.json. Точный список доступных моделей
запрашивается командой /models. Выбрать модель можно командой /model:
введите её ID либо номер из последнего списка /models.

КОМАНДЫ КОНСОЛИ
---------------
/помощь, /help       показать справку
/команды, /commands  список команд консоли и Windows PowerShell
/multi               ввести многострочное сообщение
/модели, /models     запросить список моделей провайдера
/status              показать баланс, остаток бюджета и статистику ключа AITunnel
/модель, /model      выбрать модель для текущей сессии
/new                 начать новый диалог, сохранив старый
/sessions            показать сохранённые диалоги
/resume              выбрать и продолжить диалог
/history             показать журнал текущего диалога
/сброс, /reset       начать новый диалог, сохранив старый
/выход, /exit        выйти

Стрелки вверх/вниз возвращают ранее отправленные строки. Если ввод начинается
с символа /, стрелки переключают совпадения в подсказке; Tab подставляет
выбранную команду, Enter отправляет введённый текст. В подсказке используются
исходные английские имена команд.

Обычное сообщение отправляется клавишей Enter. Для длинного текста введи
/multi, затем набери или вставь текст построчно. Отправка выполняется отдельной
строкой /send, отмена — отдельной строкой /cancel. Только имя «Олежка» в
приглашении отображается синим, только имя «Маша» — зелёным; весь ввод и текст
ответов белые. Многострочный текст сохраняется в журнале диалога, но не
добавляется в однострочную историю стрелок.

Команды клиента можно вводить по-русски. Названия команд PowerShell
оставлены на английском, как требует Windows; краткое объяснение каждой
команды показывается по-русски через /команды.

ПАМЯТКА ПО КОМАНДАМ WINDOWS
---------------------------
Файлы и папки:
  Get-Location                         текущая папка
  Set-Location C:\путь                 перейти в папку
  Get-ChildItem C:\путь                список файлов и папок
  Get-Content C:\путь\файл.txt         прочитать текстовый файл
  Set-Content C:\путь\файл.txt текст   записать текст в файл
  Copy-Item источник назначение        скопировать файл или папку
  Move-Item источник назначение        переместить файл или папку
  Remove-Item C:\путь                  удалить файл или папку
  Select-String -Path ... -Pattern ... поиск текста в файлах

Система и программы:
  Get-ComputerInfo              сведения о компьютере
  Get-CimInstance Win32_...     сведения об устройствах Windows
  Get-Process                   список процессов
  Stop-Process -Id номер        завершить процесс
  Get-Service                   список системных служб
  Start-Process программа       запустить программу или файл
  Get-Command *имя*             найти команду PowerShell
  Get-Help имя-команды          справка по команде

Сеть и диски:
  Get-NetAdapter                сетевые адаптеры
  Get-NetIPAddress              IP-адреса
  Test-NetConnection адрес      проверить сетевое соединение
  Resolve-DnsName имя           проверить DNS-имя
  Get-Volume                    диски и разделы
  Get-PSDrive                   диски и доступное место

Это памятка с примерами, а не полный каталог всех команд Windows.
Можно описать задачу обычными словами, агент подберёт команду сам.

ЛОКАЛЬНЫЙ АГЕНТ
---------------
В каждый запрос передаются схема инструмента run_powershell и параметр
tool_choice=auto. Если выбранная модель поддерживает вызов инструментов,
она может запросить запуск команды Windows PowerShell. Консоль исполняет
её автоматически, без отдельного подтверждения, от имени пользователя,
запустившего программу. Команда работает до 120 секунд; объём вывода,
передаваемого модели, ограничен 12000 символами.

Модель получает локальный инструмент, если выбранная модель поддерживает
вызов функций. Скрипт исполняет вызовы автоматически, но модель должна
соблюдать правила подтверждения опасных действий из AGENTS.md. Это не
поднимает права процесса: обычная консоль имеет права текущего пользователя,
а права администратора будут только при запуске с повышением прав Windows.
Если провайдер не вернул ID вызова инструмента, клиент создаёт свой ID и
одинаково записывает его в запрос вызова и в ответ PowerShell.

Это полный доступ в пределах прав текущей учётной записи: команды могут
читать и изменять файлы, запускать программы и обращаться к сети. Запуск
от администратора возможен, только если саму консоль открыли с повышенными
правами. Вывод команд отправляется провайдеру вместе с запросом. Не просите
агента обрабатывать конфиденциальные данные, если не согласны передать их
AITunnel. Файл api_key.cmd остаётся доступен для чтения на флешке; не
передавайте его посторонним.

Не каждая модель поддерживает вызов инструментов. Если модель вернула
обычный текст вместо вызова PowerShell, выберите модель с поддержкой
function calling в каталоге AITunnel.

ОШИБКИ
------
При сбое консоль показывает HTTP-статус, сообщение и код провайдера,
идентификатор запроса (если он передан) и тело ответа. Длинное тело
ограничивается первыми 3000 символами. При проблеме до HTTP-ответа
показывается исходная причина, например ошибка DNS или таймаут.
API-ключ автоматически маскируется и не выводится.

Диалоги сохраняются в каталоге sessions рядом с программой на флешке.
При запуске восстанавливается последняя сессия; /new создаёт новую, /sessions
показывает список, /resume открывает выбранную, /history показывает журнал.
История ввода сохраняется в sessions/command_history.txt, максимум 100 строк.
Поэтому команды доступны стрелкой вверх и после перезапуска программы.
Сохраняются реплики, выбранная модель, локальные команды и их результаты;
прерванный запрос остаётся в журнале, но автоматически не повторяется.
В обычном окне команды агента и технический ход запроса не печатаются;
ошибки провайдера остаются видимыми обычным цветом. Команды и их результаты
всё равно записываются в журнал диалога на флешке.
История хранится открытым текстом и может содержать личные данные и вывод
команд. Любой, у кого есть доступ к флешке, сможет её прочитать. Не отправляйте
каталог sessions в Git и не храните в диалогах пароли. Чтобы перенести сессии,
копируйте этот каталог вместе с программой и безопасно извлекайте флешку.
В запрос к модели отправляются только последние history_messages сообщений
из config.json (по умолчанию 20), хотя полный журнал остаётся на флешке.
Старая информация за этим пределом автоматически не суммируется, поэтому
модель может не помнить её: при необходимости укажите краткое резюме.
Программа не подключается к Codex и не получает историю этого чата. Агент
получает доступ к Windows через локальную PowerShell-команду, как описано
выше.

ОГРАНИЧЕНИЯ И ПРОВЕРКА
----------------------
Эта папка подготовлена под OpenAI-compatible API AITunnel: Chat Completions
(/chat/completions), авторизацию Bearer, список моделей (/models) и цикл
вызова инструментов. Поддержка function calling зависит от выбранной модели.
Сверяйте доступность модели и тарификацию с актуальным кабинетом AITunnel.

Команда /status выполняет GET-запросы к /aitunnel/balance и
/aitunnel/stats/summary с текущим API-ключом. Она показывает баланс аккаунта,
остаток бюджета ключа, расходы и число запросов за сегодня и за последние
30 дней. Статистика относится только к текущему ключу и может кэшироваться
провайдером примерно на час. Тест test_status.ps1 использует фиктивные ответы
и не обращается к API.
